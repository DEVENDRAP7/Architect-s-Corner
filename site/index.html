questions

Asked & answered.

What file formats does it read?

DXF — the open exchange format every AutoCAD (and most CAD software) exports natively. Working in DWG? Save-as DXF once and you're in. The app includes a guide.

Does it use AI? Can I trust the numbers?

No AI anywhere in the pipeline. Every tool is deterministic geometry code with its formula and assumptions printed alongside the result. Same drawing in, same numbers out — auditable by any engineer.

Do my drawings get uploaded somewhere?

Never. The whole app runs locally on your Windows machine. It works with the internet switched off. Client-confidential drawings stay client-confidential.

What if my drawing conventions are different?

The tools read standard tagging (C1 750×750 markers, floor level texts, F-tags). Layer-based tools show you the drawing's actual layers to pick from. Advanced options let you override any assumption per run.

Windows only?

The desktop app is Windows today (10/11). The engine is portable Python — macOS/Linux builds arrive based on demand.

Updates?

The 1.x line — every new tool and fix — is included in the one-time license. Download the new version, replace the old file, your projects carry over.
